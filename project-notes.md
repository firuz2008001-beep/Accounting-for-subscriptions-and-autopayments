# Заметки по проекту

## Модель данных (что нужно хранить)
- **Подписка (Subscription):** ID, Название, Стоимость, Периодичность (месяц/год), Дата следующего платежа, Статус (активна/отменена).
- **Платеж (Payment):** ID, ID подписки, Дата, Сумма, Статус (успешно/ошибка).

## Бизнес-логика
1. Если дата платежа прошла, а статус "активна", система должна пометить платеж как "ожидает оплаты".
2. Если автоплатеж не прошел, отправить пользователю уведомление.

## План разработки
- Планируемый релиз: декабрь (эту строку можно менять для создания конфликта).
- Следующий шаг: продумать API.
