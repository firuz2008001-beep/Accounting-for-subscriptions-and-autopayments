# Учет подписок и автоплатежей

## Описание проекта
Сервис для отслеживания ежемесячных и годовых подписок (стриминг, софт, хостинг). Позволяет пользователю вести список активных подписок, контролировать даты списаний и общую сумму ежемесячных расходов.

## Основной функционал
- Добавление и редактирование подписок.
- Просмотр предстоящих платежей.
- Категоризация расходов.
- Напоминания о скором списании средств.

## Статус
В разработке (выполнение контрольной точки по Git).
